### Maintainer notes

omaxrs is an Omarchy bar widget for the separately installed xrs Xray proxy client. Plugin ID: io.github.mahdjalili.omaxrs. Requires a configured xrs executable on the desktop session's PATH; foot is required for the TUI action. The plugin does not bundle or install xrs or Xray-core. TUN support and privileges are managed by xrs. The plugin reads status and invokes xrs actions using argument arrays, without shell interpolation. Removal leaves the client and its configuration intact and does not disconnect an active proxy session.
